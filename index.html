O que você precisa saber sobre esta apresentação.

O software já está disponível para uso?

Não. VERTEX é um nome ilustrativo para este projeto de apresentação. O painel é uma demonstração visual e não representa um produto contratado ou em operação.

Os dados do painel são reais?

Não. Os valores, quantidades e tarefas são fictícios e servem apenas para demonstrar a organização da interface.

Há integração com corretoras ou cotações?

Esta página não possui integrações. Fontes de dados, permissões e requisitos de acesso precisariam ser definidos no escopo de um produto real.

A plataforma faz recomendações de investimento?

A demonstração não recomenda ativos, prevê rendimentos ou executa operações. O objetivo é apresentar um conceito de organização de informações.
